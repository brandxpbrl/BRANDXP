# MPE Living Plasma V0.1

The Living Plasma is a semantic projection of `PossibilityGraph`, not scientific evidence and not a physical simulation.

## Mapping
- particle cluster / anchor: one available possibility node
- visible relation: graph relation or ambient connective field
- selected glow: human-selected possibility
- cluster count: graph node count
- graph state: generated from the current declared situation

## Hard boundary
Ambient particle motion is presentation. It MUST NOT be interpreted as evidence, probability, confidence, viability, persistence, attractor strength, or experimental result unless a future adapter explicitly supplies such a measured field with provenance.

The interface must preserve:
- generated != evidence
- search is non-exhaustive
- probability requires calibration
- unknown remains unknown without an evaluator
- visual form does not promote epistemic status
