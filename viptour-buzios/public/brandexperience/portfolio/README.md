# Brand Experience Portfolio

Coloca aquí tus archivos para el portafolio visual del ecosistema.

## Estructura

- `logos/` para logos finales, variantes y versiones monocromáticas
- `identidades/` para boards, propuestas, sistemas de marca y lineamientos
- `brand-systems/` para manuales, paletas, tipografías y elementos de sistema
- `mockups/` para presentaciones y aplicaciones visuales
- `social/` para piezas para redes sociales
- `video/` para piezas en video o reels

## Recomendación de nombres

- `marca-logo-principal.png`
- `marca-logo-blanco.png`
- `marca-logo-negro.png`
- `marca-icono.png`
- `marca-identity-board.png`

## Regla práctica

- Usa nombres cortos y sin espacios.
- Agrupa una sola marca por carpeta cuando sea posible.
- Mantén solo material final o casi final dentro de esta biblioteca.
